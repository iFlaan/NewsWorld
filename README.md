## 📖 نبذة

**NewsWorld** تطبيق ويب خفيف بصفحة واحدة، يعرض الأخبار والأحداث العالمية على خريطة تفاعلية، ويتحدّث تلقائياً من مصادر عامة دون الحاجة إلى خادم خلفي (Backend). كل شيء يعمل في المتصفح مباشرة.

> 🌐 **عرض مباشر:** [https://iflaan.github.io/NewsWorld/](https://iflaan.github.io/NewsWorld/)

| الميزة | التفاصيل |

## 🧱 التقنيات المستخدمة

- **HTML5 + CSS3** (متغيّرات CSS، Grid، `prefers-color-scheme`)
- **JavaScript (ES Modules)** — بدون أي إطار عمل

## 🚀 التشغيل

### 1. تشغيل محلي (للتطوير)

المشروع يستخدم **ES Modules**، لذلك لا يعمل بفتح `index.html` مباشرة من القرص. تحتاج خادماً محلياً بسيطاً:

```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx serve
```

ثم افتح: http://localhost:8000

2. النشر على GitHub Pages

1. ارفع الملفات إلى مستودعك.
2. اذهب إلى: Settings → Pages
3. اختر: Source: Deploy from a branch → Branch: main / (root)
4. اضغط Save وانتظر دقيقة.
5. سيظهر رابطك: https://<username>.github.io/NewsWorld/

⚠️ مهم: افتح الصفحة من رابط GitHub Pages وليس من الملف المحلي، لأن:

· YouTube يرفض التضمين من file://
· ES Modules لا تعمل من الملف المحلي في معظم المتصفحات

⚙️ التخصيص

كل الإعدادات موجودة في js/config.js — لا تحتاج للمس أي ملف آخر لتخصيص المحتوى:

ما تريد تعديله المفتاح في config.js
إضافة/حذف مصدر RSS FEEDS
إضافة/حذف قناة بث TV
سرعة التحديث FAST (الأخبار) و SLOW (الأحداث)
أنواع الطبقات وألوانها L
الكلمات المفتاحية لاستنتاج المواقع GEO
البؤر الثابتة على الخريطة BASE
مصدر بيانات الحدود الجغرافية WORLD_URL

مثال — إضافة مصدر RSS جديد:

```js
// في js/config.js داخل مصفوفة FEEDS
["اسم المصدر", "https://example.com/rss.xml", "https://example.com"],
```

مثال — تغيير سرعة التحديث:

```js
export const FAST = 60000;   // الأخبار كل دقيقة
export const SLOW = 180000;  // الأحداث كل 3 دقائق
```

لتعديل التصميم: كل الأنماط في css/style.css وتعتمد على متغيّرات CSS في :root، فيمكنك تغيير الألوان أو الخطوط من مكان واحد.

🗺️ كيف يعمل؟

1. الجلب: عند فتح الصفحة، تُجلب الأخبار من المصادر عبر fetch مع نظام بروكسي احتياطي (CORS) في حال فشل المصدر المباشر.
2. التحليل: يُحلَّل RSS عبر DOMParser، وتُستخرج العناوين والروابط والتواريخ.
3. الاستنتاج الجغرافي: يُخمَّن موقع الخبر من الكلمات المفتاحية في العنوان (قائمة GEO).
4. الرسم: تُرسم النقاط على خريطة Canvas باستخدام D3.js، وتُعاد رسمها فقط عند الحاجة.
5. التحديث: مؤقتان مستقلان: FAST للأخبار و SLOW للأحداث. التحديث يتوقف عند إخفاء التبويب لتوفير الموارد.
