# NewsWorld

غرفة أخبار عربية تفاعلية تعرض أحدث العناوين مع نسبتها إلى الناشرين الأصليين، وتفصلها عن مؤشرات التغطية الجغرافية والأحداث الطبيعية على الخريطة. تتضمن أيضاً روابط ومشغلاً لبث الجزيرة والعربية والحدث من صفحاتها الرسمية أو قنوات YouTube الرسمية.

## الميزات

- عناوين حديثة من خلاصات RSS للجزيرة نت، وBBC News عربي، وفرانس 24 عربي، مع إظهار حالة العربية عند حجب خلاصتها.
- مواد إضافية من GDELT عند توفر واجهته؛ لا يعرض التطبيق عناوين ثابتة على أنها حية.
- تحديث تلقائي للأخبار كل دقيقتين، وللأحداث والخريطة كل خمس دقائق، مع زر تحديث يدوي.
- بحث موحد، وتصفية بحسب الناشر أو طبقة الحدث، وقائمة متزامنة مع الخريطة.
- بيانات الزلازل من USGS، والكوارث الطبيعية المفتوحة من NASA EONET، ومؤشرات التغطية الجغرافية من GDELT.
- بث رسمي لقنوات الجزيرة والعربية والحدث. يعمل مشغل واحد في الوقت نفسه، مع رابط إلى موقع القناة وYouTube كبديل.
- واجهة عربية RTL متجاوبة، مع مظهرين داكن وفاتح، واختصار للبحث، ودعم `prefers-reduced-motion`.

## التشغيل المحلي

يستخدم الموقع JavaScript ES Modules، لذلك شغّله من خادم HTTP محلي بدلاً من فتح ملف HTML مباشرة:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## المصادر والقيود

- الجزيرة نت: `https://www.aljazeera.net/rss`
- العربية: `https://www.alarabiya.net/feed/rss2/ar/arab-and-world.xml`، وصفحة خدمة RSS الرسمية: `https://www.alarabiya.net/tools/mrss`
- BBC News عربي: `https://feeds.bbci.co.uk/arabic/rss.xml`، وتفاصيل RSS: `https://www.bbc.com/arabic/institutional/2011/01/000000_rss`
- فرانس 24 عربي: `https://www.france24.com/ar/rss`، وصفحة RSS: `https://www.france24.com/ar/خدمة-RSS`
- البث الرسمي: [الجزيرة](https://www.aljazeera.net/video/live)، [العربية](https://www.alarabiya.net/live-stream)، [الحدث](https://www.alhadath.net/live-stream).

تُعرض العناوين والروابط ولا تُنسخ المقالات كاملة. بعض الناشرين لا يتيحون ترويسة CORS اللازمة للجلب المباشر من صفحة ثابتة؛ عندها يطلب التطبيق الخلاصة عبر Jina Reader بصيغة XML الخام (ثم يحاول Markdown كخيار أخير). أثناء الاختبار أعاد هذا المسار عناوين RSS وروابط 25 مادة من الجزيرة و25 من BBC و24 من فرانس 24. قد يتوقف الوسيط أو تختلف نتائجه حسب المنطقة والناشر. خلاصة العربية أعادت 403 وطلبت CAPTCHA في الاختبار، لذا تظهر كمتعذرة بدلاً من استبدالها ببيانات غير موثوقة. كما لم يستجب GDELT من بيئة الاختبار ضمن مهلة الاتصال. لا يوجد خادم خلفي أو مفتاح API ضمن المشروع، لذلك لا يمكن ضمان تغطية كل خبر عالمي أو تحديث لحظي قبل الناشر.

قد يمنع مزود البث التضمين أو يقيّد المشاهدة حسب البلد؛ عندها استخدم الرابط الرسمي المعروض في نافذة القنوات. لا يبدأ الصوت تلقائياً.

مؤشرات GDELT على الخريطة تقديرات للتغطية الجغرافية وليست تحديداً دقيقاً لمكان كل مقال. بيانات USGS وNASA تخص أحداثها المسجلة، ولا تمثل قائمة بكل الأحداث العالمية. كل خبر يظل منسوباً إلى ناشره الأصلي.

## التقنية

HTML وCSS وJavaScript ES Modules، وMapLibre GL JS، وخريطة OpenFreeMap. لا يتطلب المشروع حزمة بناء أو حساباً أو مفتاح API.
